# Фикстуры Wildberries

Здесь лежат файлы `<код магазина>.json` — то, что отдал бы API WB. На них работает
`FixtureWbClient` и идёт разработка без боевых ключей.

Файлы в репозиторий не коммитятся: они генерируются и привязаны к текущей дате.
Создать их вместе с демо-данными:

```bash
cd backend && python -m app.seed --reset
```

Формат:

```json
{
  "cards":  [{ "nm_id": "01498277356", "vendor_code": "498277356", "title": "...", "category": "Аксессуары" }],
  "sales":  [{ "nm_id": "01498277356", "day": "2026-09-14", "order_units": 5.2, "buyout_units": 4.0, "sales_units": 4.0 }],
  "stocks": [{ "nm_id": "01498277356", "day": "2026-09-20", "quantity": 243 }]
}
```

`sales` — дневные строки, сворачиваются в недельные суммы. `stocks` — срезы остатка;
за неделю берётся последнее значение, суммировать их нельзя.

Если файла для магазина нет, клиент возвращает пустые списки, а синхронизация
отрабатывает без ошибки и просто ничего не обновляет.
